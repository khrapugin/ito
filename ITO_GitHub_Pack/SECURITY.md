# Данные и границы использования

Поставка содержит синтетические примеры. Рабочие базы и личные ответы в неё не копируются. При публикации используйте только содержимое этого пакета.

`docs` предназначен для публичной демонстрации. У него нет общей базы, отправки формы или постоянного хранилища ответов. После обновления восстанавливается учебный пример.

`app` предназначен для локальной проверки на `127.0.0.1:8010`. Авторизация и разделение ролей отсутствуют; не открывайте этот сервер для интернета до реализации требований из DEPLOYMENT.md. SQLite и JSON-копии не зашифрованы средствами приложения. Личный дневник доступен тому, кто имеет доступ к профилю браузера.

`.gitignore` исключает SQLite, базы, `.env`, резервные копии, runtime-тесты и локальные окружения. Он не удаляет ранее добавленные в Git файлы: не помещайте в этот репозиторий реальные рабочие выгрузки и личные данные.

Сведения об уязвимостях направляйте владельцу репозитория по выбранному им закрытому каналу. Не публикуйте в открытом issue реальные ответы сотрудников, секреты или рабочие базы.
